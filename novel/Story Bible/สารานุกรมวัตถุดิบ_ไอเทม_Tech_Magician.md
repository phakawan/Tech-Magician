# สารานุกรมวัตถุดิบและไอเทม (Master)

> เวอร์ชันขยายเพื่อใช้งานในนิยายระยะยาว
> 
> จุดประสงค์ของไฟล์นี้คือรวบรวม “วัตถุดิบ / อุปกรณ์ / ของพิเศษ / ของต้องห้าม” ที่ใช้ในโลกของเรื่อง ให้มีจำนวนมากพอสำหรับการเขียนนิยายยาวโดยไม่ต้องคิดของใหม่สดทุกครั้ง
>
> หลักการใช้งาน:
> - ใช้วัตถุดิบแต่ละชนิดให้สอดคล้องกับ `ระบบเวทมนตร์_master.md` และ `กฎโลก_master.md`
> - วัตถุดิบ 1 ชนิดไม่จำเป็นต้องใช้ได้กับทุกธาตุ
> - ของหายากควรมี “ราคา” หรือ “ความเสี่ยง” เสมอ
> - วัตถุดิบระดับสูงไม่ควรทำให้ทุกปัญหาง่ายเกินไป ต้องมีข้อจำกัดหรือผลข้างเคียง

---

## 1) ระดับความหายาก

- **สามัญ** — หาได้ทั่วไปในตลาดช่าง / เมืองใหญ่ / ร้านซ่อมไม้กายสิทธิ์
- **กึ่งหายาก** — มีเฉพาะร้านเฉพาะทาง / ต้องสั่ง / ต้องออกหาในธรรมชาติ
- **หายาก** — ใช้ในงานแข่งขัน งานวิจัย หรือไม้กายสิทธิ์ระดับสูง
- **สูงมาก** — เกี่ยวข้องกับตระกูลช่างระดับสูง มิราเคิลเมจ หรือของจากเขตอันตราย
- **ต้องห้าม / ควบคุม** — ผิดกฎหมาย มีประวัติถูกใช้ทำอาวุธ หรือเกี่ยวพันกับคทา / องค์กรใต้ดิน

---

## 2) โครงสร้างไม้กายสิทธิ์ (เตือนความจำ)

ไม้กายสิทธิ์มาตรฐานประกอบด้วย
- เปลือกนอก
- แก่น
- อัญมณีเสริมพลัง
- เส้นประสาทของไม้กายสิทธิ์ (มาตรฐานใหม่แบบอีวาน)
- สารประสาน / ตัวช่วยประกอบ

คทาใช้หลักการใกล้เคียงกัน แต่รองรับพลังในปริมาณสูงกว่า และมักใช้กับผู้มีพลังเวทหรือกระแสจิตสูงมาก

# หมวด A: วัตถุดิบส่วนเปลือก (Shell / Casing Materials)

## A1. เปลือกไม้สายมาตรฐาน

### 1. ไม้ไผ่ขาว
- ระดับ: สามัญ–กึ่งหายาก
- ธาตุที่เข้ากัน: ลม
- คุณสมบัติ: ยืดหยุ่นสูง ส่งกระแสจิตได้ลื่น ปรับทิศทางเวทง่าย
- เด่นเรื่อง: เวทธาตุลมระดับกลาง / เวทที่ต้องอาศัยความพลิกแพลง
- จุดอ่อน: รับแรงอัดของเวทระดับสูงได้ไม่ดี
- หมายเหตุ: ใช้ในไม้ของเซฟิรอสตาม canon เดิม

### 2. ไม้สนอัคคี
- ระดับ: กึ่งหายาก
- ธาตุที่เข้ากัน: ไฟ
- คุณสมบัติ: เก็บความร้อนดี ตอบสนองเวทไฟไว
- เด่นเรื่อง: เวทไฟแบบปะทุ / ระเบิดพลังเร็ว
- จุดอ่อน: ถ้าประสานไม่ดีมีโอกาสแตกร้าวเมื่อเร่งพลังต่อเนื่อง
- หมายเหตุ: ใช้ในไม้เดิมของเวียรา

### 3. โรสวู้ด
- ระดับ: หายาก
- ธาตุที่เข้ากัน: กลาง / รองรับหลายธาตุ
- คุณสมบัติ: เนื้อไม้แข็งมาก เสถียรสูง เหมาะกับงานทดลองที่เสี่ยงระเบิด
- เด่นเรื่อง: งานออกแบบซับซ้อน / ไม้หลายแก่น / ไม้ผสมธาตุ
- จุดอ่อน: เหลาและขึ้นรูปยาก ใช้เวลาทำสูง
- หมายเหตุ: ใช้ในงานผสมธาตุของอีวานในช่วงแข่งขัน

### 4. ไม้อะการ์วู้ด
- ระดับ: หายาก
- ธาตุที่เข้ากัน: เวทไร้ธาตุ / สายแพทย์ / สายจิตนิ่ง
- คุณสมบัติ: กลิ่นไม้ช่วยลดการสั่นของกระแสจิต
- เด่นเรื่อง: เวทรักษา เวทปลอบประสาท เวทชำระล้าง
- จุดอ่อน: ไม่เด่นเรื่องพลังระเบิดหรือเวทโจมตีหนัก
- หมายเหตุ: ใช้ในไม้ของโฮลี่ตาม canon เดิม

### 5. ทีคยักษ์
- ระดับ: หายาก
- ธาตุที่เข้ากัน: กลาง / สายภาพลักษณ์ / ไม้พิธีการ
- คุณสมบัติ: สวย หรู ทน ใช้งานได้ดีในภาพรวม
- เด่นเรื่อง: ไม้สำหรับชนชั้นสูง งานประกวด งานเชิงสถานะ
- จุดอ่อน: ไม่ได้เด่นสุดทางเทคนิคเมื่อเทียบกับวัตถุดิบเฉพาะทาง
- หมายเหตุ: ใช้โดยไอออสในการแข่งขัน

### 6. ไม้มะเกลือรัตติกาล
- ระดับ: หายาก
- ธาตุที่เข้ากัน: ดิน / ความมืด / เวทกดทับ
- คุณสมบัติ: ดูดซับแรงสะท้อนได้ดี ทำให้เวทนิ่งและหนัก
- เด่นเรื่อง: เกราะเวท กำแพง พันธนาการ
- จุดอ่อน: เวทที่ต้องการความไวจะหน่วงกว่าวัสดุอื่น

### 7. ไม้เงินจันทร์
- ระดับ: หายาก
- ธาตุที่เข้ากัน: น้ำ / เวทแสง / เวทสมดุล
- คุณสมบัติ: ผิวไม้สะท้อนแสงจันทร์ ทำให้การไหลของกระแสจิตนุ่มขึ้น
- เด่นเรื่อง: เวทน้ำแบบควบแน่น เวทฟื้นฟูเบา ๆ เวทปกปิด
- จุดอ่อน: พลังปะทะไม่สูง

### 8. ไม้แอชทะเล
- ระดับ: กึ่งหายาก
- ธาตุที่เข้ากัน: น้ำ / ลม
- คุณสมบัติ: ทนไอเกลือและความชื้น เหมาะกับเมืองท่าและนักเดินเรือ
- เด่นเรื่อง: เวทหมอก ฝน คลื่น
- จุดอ่อน: ไฟระดับสูงทำให้เนื้อไม้เสียสภาพเร็ว

### 9. ไม้โอ๊คภูผา
- ระดับ: กึ่งหายาก
- ธาตุที่เข้ากัน: ดิน
- คุณสมบัติ: รับแรงกระแทกดีมาก หนักแน่น
- เด่นเรื่อง: เวทดินระดับกลางถึงสูง แนวรับ คงรูป
- จุดอ่อน: ใช้กับเวทที่เปลี่ยนรูปเร็วแล้วช้า

### 10. ไม้เถ้าภูเขาไฟ
- ระดับ: สูงมาก
- ธาตุที่เข้ากัน: ไฟ / ดิน
- คุณสมบัติ: ผ่านความร้อนจัดมาแล้ว จึงทนแรงปะทุภายในสูง
- เด่นเรื่อง: ลาวา เพลิงหนัก เวทผสมไฟ–ดิน
- จุดอ่อน: เปราะถ้าถูกเร่งกระแสจิตแบบสลับธาตุบ่อย

## A2. เปลือกประเภทสิ่งมีชีวิต / พืชประหลาด

### 11. เถาวัลย์ปีศาจ

### 12. ปรงหางกระรอก

- ธาตุที่เข้ากัน: กลาง
- คุณสมบัติ: ก้านทำหน้าที่คล้ายเส้นประสาท จัดระเบียบการไหลของกระแสจิต

### 13. กิ่งสนธยาขยับ

- คุณสมบัติ: ขยับตามแสงเงาอ่อน ๆ ได้เอง
- เด่นเรื่อง: ไม้ลอบเร้น ไม้ดักซ่อนเวท
- จุดอ่อน: ไม่เหมาะกับผู้ใช้ที่กระแสจิตไม่นิ่ง

### 14. เปลือกมอสคริสตัล
- ระดับ: กึ่งหายาก
- ธาตุที่เข้ากัน: น้ำ / ชีวิต
- คุณสมบัติ: เก็บความชื้นและเวทอ่อนโยนได้ดี
- เด่นเรื่อง: เวทรักษา เวทฟื้นฟู เวทปลูกพืช
- จุดอ่อน: สู้เวทปะทะรุนแรงไม่ได้

### 15. เถาเหล็กฟ้า

- ธาตุที่เข้ากัน: ลม / สายฟ้าเชิงอาคม

# หมวด L: ข้อเสนอสำหรับการใช้ในนิยายต่อ

## 1. กฎกันพัง
- อย่าให้วัตถุดิบใหม่แก้ทุกปัญหาได้ทันที
- ของระดับตำนานควรมีราคาทางพล็อต เช่น หายาก, ใช้ยาก, ต้องมีคนคุม, เสี่ยงแตก
- ของต้องห้ามควรทิ้งร่องรอยทั้งทางเวท ทางกฎหมาย หรือทางจิตใจ

## 2. กฎกันซ้ำ
- ถ้าใช้วัตถุดิบเดิมบ่อย ให้เปลี่ยนบริบทการใช้งาน
- ถ้าจะสร้างไม้ใหม่ให้ตัวละครหลัก ใช้ “ชุดวัตถุดิบ” สะท้อนพัฒนาการตัวละคร ไม่ใช่แค่เพิ่มความแรง

## 3. กฎกันล้น
- ใน 1 ตอน ไม่ควรยัดวัตถุดิบใหม่เกิน 2–3 ชนิดถ้าไม่ได้จำเป็น
- วัตถุดิบใหม่ที่สำคัญ ควรได้โชว์ “ผลของมัน” ไม่ใช่แค่โผล่ชื่อผ่าน ๆ

# สรุปแกนการใช้งาน

ถ้าจะใช้ไฟล์นี้ให้คุ้มที่สุด ให้คิดแบบนี้:
- **เปลือก** = บุคลิกและการรองรับพลัง
- **แก่น** = ธรรมชาติของเวทหลัก
- **อัญมณี** = วิธีขยาย / ปรับเนื้อเวท
- **เส้นประสาท** = ประสิทธิภาพ / ความเป็นระเบียบ / งานนวัตกรรม
- **สารประสานและตัวเร่ง** = ทำให้ของที่ “เป็นไปไม่ได้” พอเป็นไปได้ชั่วคราว
- **ของต้องห้าม** = ด้านมืดของเทคโน-เวท
