# อภิธานศัพท์ (Master Glossary — Canon)

> เป้าหมาย: รวมคำศัพท์เฉพาะ ชื่อ canonical และนิยามที่ล็อกเป็น source-of-truth
> สำหรับงาน rewrite, เอเจนต์ใน pipeline และการอ้างอิงข้ามไฟล์

การใช้งานโดยย่อ:
- ไฟล์นี้เป็นแหล่งอ้างอิงหลัก (source-of-truth) สำหรับชื่อและคำศัพท์
- หากต้องเปลี่ยนชื่อหลัก ให้บันทึกการเปลี่ยนแปลงพร้อมเหตุผลและแหล่งอ้างอิง

## ชุดชื่อหลัก (Canonical names)
- **วาเลเรียน** — นครรัฐเวทมนตร์ศูนย์กลางในปัจจุบัน (canonical). คำพ้อง/ชื่อเก่า: อาเคนเนีย
- **ออเรนทิส** — เมืองเล็กทางใต้ (บ้านเกิดอีวาน). คำพ้อง/ชื่อเก่า: โคโรบา
- **เมอริดัส** — เมืองท่า / จุดเชื่อมเครือข่ายสีเทาและนักล่าเงินรางวัล
- **ซิลวาเรีย** — นครเก่าแห่งป่า (อดีตหนึ่งในสี่นคร)
- **ธีอาริส** — นครเก่าแห่งความสันโดษ (อดีตหนึ่งในสี่นคร)
- **จักรวรรดิราตรีทมิฬ** — ฝ่ายศัตรูทางเหนือ

## คำศัพท์เชิงระบบเวท (Core magic terms)
- **ไม้กายสิทธิ์** — เครื่องมือเวทส่วนบุคคล (ผูกเลือด + ต้องเข้ากับกระแสจิต)
- **คทา** — เครื่องมือเวทอีกประเภท เหมาะกับผู้ใช้พลังสูงและรองรับพลังปริมาณมาก
- **กระแสจิต** — วิธี/ช่องทางในการส่งและควบคุมพลังเวท (ใช้คำนี้เป็นหลัก)
- **พลังเวท** — ปริมาณพลังในตัวผู้ใช้
- **เจตจำนงของไม้** — จุดประสงค์เชิงการออกแบบของไม้แต่ละอัน (สำคัญต่อประสิทธิภาพ)
- **เส้นประสาทของไม้** — (นวัตกรรมของอีวาน) ส่วนที่ 4 ของไม้กายสิทธิ์ ที่จัดระเบียบการไหลของกระแสจิต
- **ไม้เฉพาะทาง** — ไม้แบบใช้แล้วทิ้งที่บันทึกเวทไว้ล่วงหน้า (game changer)
- **ไม้ผสมธาตุ** — ไม้ที่รองรับแก่นหลายชนิดเพื่อผสมธาตุในอันเดียว
- **ไม้กายสิทธิ์สั่งตาย** — อาวุธเวทร้ายแรง (ห้ามเฉลยกลไกเร็ว; ระวัง power-creep)
- **คทาจตุโลกบาล** — ชุดคทา 4 ชิ้นระดับตำนาน (Order / Chaos / Life / Death)

## ตัวละครสำคัญ (ย่อ)
- **อีวาน** — พระเอก, ช่างทำไม้กายสิทธิ์จากออเรนทิส, นวัตกรเส้นประสาทของไม้
- **เวียรา** — คู่หูหลัก, มิราเคิลเมจอันดับ 7, พลังไฟ
- **มีรา** — มิราเคิลเมจ / รุ่นพี่ / ปมคาเอล
- **ลูเซียน** — มิราเคิลเมจ / จอมเวทแพทย์ / ผู้ใช้คทา
- **อัลดริค** — ผู้อาวุโส / mentor ของอีวาน / ช่างชั้นครู
- **ออเรลิออน** — จอมเวทสูงสุด (ถือคทาแห่งระเบียบ)
- **ซีรัน / เวจ** — ฝ่ายตรงข้ามสำคัญ (ชื่อและสถานะควรล็อกในไฟล์ชื่อตัวละคร)

(รายชื่อตัวละครโดยละเอียดดู [ชื่อตัวละคร_master](ชื่อตัวละคร.md))

## องค์กรและหน่วย
- **มิราเคิลเมจ** — หน่วยกำลังรบพิเศษ (ลำดับ 1–7)
- **ผู้อาวุโสทั้งห้า** — แกนอำนาจยาวนานของวาเลเรียน
- **เซเวอแรนซ์** — เครือข่ายใต้ดินผลิต/ค้าอาวุธเถื่อน
- **สำนักปักษามนตรา** — สำนักนอกรีต (เควทซัลสังกัด)

## วัตถุดิบ / ไอเทมสำคัญ (ย่อ)
- **ปรงหางกระรอก** — วัตถุดิบเส้นประสาทของไม้ (ตัวอย่าง)
- **ขี้เถ้าเวท, น้ำมันปลุกเวท** — วัตถุดิบสำคัญของไม้เฉพาะทาง
- **อัญมณี (โกเมน, มรกต, คริสตัลใสเจ็ดสี, เพชรเม็ตโต)** — อัญมณีเสริมพลังที่ปรากฏบ่อย
- **หีบเครื่องมือ, หนังสือตระกูล, เครื่องบดไม้, กล่องอัดแก่น** — ไอเทมเชิงช่างสำคัญ

## Artifacts & Legend
- **คทาแห่งระเบียบ** — ปัจจุบันอยู่กับจอมเวทสูงสุด / บัลทาซาร์
- **คทาแห่งความตาย** — เชื่อว่าตกอยู่กับจักรวรรดิราตรีทมิฬ
- **คทาแห่งความโกลาหล / คทาแห่งชีวิต** — สถานะสูญหาย/ไม่ชัดเจน (ล็อกไว้)

## การเรียกชื่อและคำพ้อง (Usage rules)
- ให้ใช้คำในหมวด "ชุดชื่อหลัก" เป็น canonical เสมอ
- ถ้าพบชื่อเก่าหรือชื่อทางเลือก ให้บันทึกคำพ้องไว้ในวงเล็บ เช่น `ออเรนทิส (โคโรบา)`
- ห้ามเปลี่ยน canonical name โดยไม่บันทึกและอ้างไฟล์นี้

## หมายเหตุการใช้งาน
- ไฟล์นี้คือ source-of-truth — เอเจนต์ทุกตัวและผู้เขียนควรอ้างอิงก่อนแก้ canon
- การเพิ่มคำศัพท์: ระบุ `คำ` / `นิยามสั้น` / `แหล่งที่มา (ไฟล์/บท)` / `สถานะ (locked|provisional)`
- เมื่อต้องการแก้ปัญหาชื่อขัดกัน ให้ยึด `novel/Story Bible/กฎโลก.md` เป็นหลักเมื่อไฟล์นั้นชี้ชัด
