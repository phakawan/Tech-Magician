# Review Output Schema

This folder stores review reports for completed chapters.

## Structure
- `novel/Review/Writer/<Arc>/ตอนที่ XX - <ชื่อบท>.md`
- `novel/Review/Editor/<Arc>/ตอนที่ XX - <ชื่อบท>.md`

## Writer Review
- Focuses on chapter shape, pacing, scene completeness, and story delivery.
- Produces a pass/revise verdict plus actionable revision notes.

## Editor Review
- Focuses on line-level polish, rhythm, fluency, and final readability.
- Produces a pass/revise verdict plus final editorial notes.
