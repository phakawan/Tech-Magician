# Arc 3 — ไม้กายสิทธิ์สั่งตาย: Scene Cards (30 ตอนเต็ม)

## Overview
- ชื่อ Arc: ไม้กายสิทธิ์สั่งตาย
- ช่วงตอน: 61–90
- ช่วงเวลา canon: `Month 5–7`
- เป้าหมายของ Arc: พาอีวานจากช่างประจำโครงการในวาเลเรียนเข้าสู่สนามรบจริง ทำให้เขาเห็นชัดว่าความรู้ของตัวเองถูกใช้ได้ทั้งเพื่อช่วยชีวิตและเพื่อฆ่าคน พร้อมเปิดประตูสู่ความจริงระดับโลกเรื่องไม้สั่งตาย คทา และสี่นคร
- POV หลักของ Arc: อีวาน / เวียรา / เซเรน่า
- POV รองใช้เฉพาะเมื่อ scene ต้องพึ่งมุมมองทางคำสั่ง สนาม หรือเอกสารจริง ๆ
- หน้าที่ของ Arc:
  1. เปลี่ยน “งานช่าง” ให้กลายเป็น “อาวุธของสงคราม” อย่างเป็นรูปธรรม
  2. ให้คนอ่านเห็นว่าแนวหน้ากำลังตอบสนองต่อหลักคิดของอีวาน ไม่ใช่แค่ผลผลิตของเขา
  3. เปิดข้อมูลโบราณเรื่องคทาและสี่นครพอให้โลกใหญ่ขึ้น แต่ยังไม่เฉลยลึกสุด
  4. ดันความสัมพันธ์อีวาน–เวียราให้เป็นคู่หูภาคสนามจริง
  5. ทำให้ความกลัวของอีวานต่อสิ่งที่ตัวเองสร้างชัดขึ้นเรื่อย ๆ
- จังหวะของ Arc:
  - ตอน 61–66 เปิดภัยและแยกให้เห็นว่า “ของ” ชิ้นนี้ฆ่าคนอย่างไร
  - ตอน 67–72 เปิดความรู้โบราณพอให้โลกขยาย แต่ไม่เฉลยสุดทาง
  - ตอน 73–78 ให้ศัตรูโต้กลับและบีบให้การช่วยชีวิตกลายเป็นสนามฆ่า
  - ตอน 79–84 ทำให้ต้นทุนของความรู้ตกมาถึงมืออีวานโดยตรง
  - ตอน 85–90 ปิดด้วยผลทางอารมณ์และการยอมรับว่าศึกนี้ไม่ใช่เรื่องชั่วคราว
- จุดพีคกลาง Arc: ตอน 73–78 ต้องเป็นช่วงที่อีวานเห็นไม้สั่งตายถูกใช้จริง และเข้าใจว่าศัตรูไม่ได้ลอกเขาแบบหยาบ ๆ แต่กำลังอ่านระบบของเขาในระดับใกล้เคียง
- ภาพจำของ Arc:
  - รายงานสนามที่มีคราบเลือดและคำสรุปที่เย็นเกินไป
  - ไม้หักที่เผยรอยชั้นในซึ่งไม่ควรมีอยู่
  - แผนที่สี่นครที่ถูกวางบนโต๊ะบัญชาการกลางเสียงศึก
  - มือของอีวานที่มั่นคงขึ้นกับงาน แต่สั่นลงเมื่อเห็นผลลัพธ์จริง
- จังหวะ hook:
  - ทุก 2–3 ตอนต้องจบด้วยข้อมูลใหม่, การตาย, หรือการตัดสินใจที่บีบให้เรื่องเดินต่อ
  - หลีกเลี่ยงการปิดตอนด้วยข้อมูลเชิงอธิบายล้วน ถ้าไม่มีภาพหรือผลกระทบให้จำ
  - ตอนกลาง arc ควรทิ้งคำใหม่หรือสัญลักษณ์ใหม่ทุกครั้งที่ความรู้ของอีวานถูกทดสอบ
- กติกา arc นี้:
  - ยังไม่เปิดความจริงเต็มของเอเรน, คาเอล, เซเวอแรนซ์, หรือรากโคโรบา
  - ให้ “ไม้สั่งตาย” เป็นภัยเชิงระบบ ไม่ใช่อาวุธเวทธรรมดา
  - คทาและสี่นครต้องมีบทบาทในปัจจุบัน แต่ยังไม่ลงรายละเอียดทั้งหมด
  - เวียราต้องตรง แรง และลงมือจริง ไม่กลายเป็นนักการเมือง
  - ทุกครั้งที่อีวานชนะ ต้องมีราคาหรือความเสี่ยงตามมา

## ตอน 61: รายงานเลือด
- POV: อีวาน
- สถานที่/เวลา: ห้องทดลองย่อยฝั่งตะวันออก / ดึก
- Objective: อ่านรายงานจากแนวหน้าและทำความเข้าใจว่าพวกเขากำลังต้องการอะไรจากเขา
- Conflict/Obstacle: รายงานเต็มไปด้วยคำที่ฟังเหมือนเอกสารทหาร แต่ปัญหาจริงคือคนเจ็บเริ่มตายจากสิ่งที่มาตรฐานเดิมรับไม่อยู่
- Outcome: อีวานเห็นว่าคำขอรอบนี้ไม่ใช่การสั่งของธรรมดา แต่เป็นการเรียกคนที่เข้าใจโครงสร้างของอาวุธ
- Reveal: งานของเขาเริ่มถูกมองในฐานะส่วนหนึ่งของยุทธศาสตร์สงครามแล้ว
- Hook ปลายตอน: บรรทัดท้ายของรายงานบอกว่า ศัตรูเริ่มใช้ “ไม้” ตอนการช่วยเหลือเริ่มทำงาน

## ตอน 62: คำสั่งลงแนวหน้า
- POV: เซเรน่า
- สถานที่/เวลา: ห้องประชุมภายใน / เช้า
- Objective: ตัดสินว่าควรส่งอีวานและเวียราไปแนวหน้าหรือยัง
- Conflict/Obstacle: ฝ่ายหนึ่งอยากล็อกอีวานไว้ในเมือง อีกฝ่ายต้องการของแก้สนามทันที และไม่มีใครอยากรับผิดถ้าพาเด็กช่างไปตาย
- Outcome: เซเรน่าผลักคำสั่งคุ้มกันพร้อมภารกิจร่วมให้ผ่าน เพื่อส่งอีวานไปแนวหน้าภายใต้กรอบที่ยังคุมได้
- Reveal: วาเลเรียนยอมรับแล้วว่าอีวานไม่ใช่แค่ช่างในหอวิจัย แต่เป็นทรัพยากรเชิงสงคราม
- Hook ปลายตอน: ชื่อแรกในรายงานคือคนที่ทุกคนคิดว่ายังมีชีวิตอยู่

## ตอน 63: ขบวนลำเลียงก่อนถึงแนวหน้า
- POV: เวียรา
- สถานที่/เวลา: ถนนเส้นเหนือ / กลางวัน
- Objective: พาอีวานไปแนวหน้าโดยไม่ปล่อยให้ระบบกลืนเขาไปก่อนถึงที่หมาย
- Conflict/Obstacle: ขบวนลำเลียง เตียงคนเจ็บ และเจ้าหน้าที่หลายสายทำให้การเดินทางกลายเป็นงานโลจิสติกส์มากกว่าการย้ายคน
- Outcome: เวียราเห็นชัดว่าพลังของเมืองถูกใช้กลบความจริงของสงครามยังไง และอีวานก็เริ่มเห็นว่าทางไปแนวหน้าไม่ใช่เส้นตรง
- Reveal: สงครามในโลกนี้คือระบบขนคน ขนของ และขนความตายไปพร้อมกัน
- Hook ปลายตอน: คนเจ็บชี้ไปที่ไม้หักชิ้นหนึ่งแล้วเรียกมันด้วยชื่อที่ไม่มีใครอยากได้ยิน

## ตอน 64: ต้นแบบสั่งตาย
- POV: อีวาน
- สถานที่/เวลา: ค่ายพยาบาลชั่วคราว / บ่าย
- Objective: ตรวจต้นแบบที่ถูกใช้จริงในสนามและดูว่ามันเสียหายเพราะอะไร
- Conflict/Obstacle: ผู้บาดเจ็บมากเกินไป, เวลาน้อยเกินไป, และไม่มีใครอยากหยุดงานเพื่อให้เด็กช่างไล่รื้อชิ้นส่วน
- Outcome: อีวานเริ่มจับรูปแบบความเสียหายที่ไม่เหมือนการใช้ผิดธรรมดา และรู้ว่าของบางชิ้นถูกออกแบบมาให้พังในจังหวะที่ช่วยชีวิตไม่ได้
- Reveal: ไม้สั่งตายไม่ได้ออกฤทธิ์แค่จากพลัง มันเล่นกับวิธีใช้งานของคน
- Hook ปลายตอน: เขาพบชิ้นส่วนที่เหมือนถูก “อ่านกลับ” จนแกนในเสียรูป

## ตอน 65: จุดตายของการช่วยเหลือ
- POV: อีวาน
- สถานที่/เวลา: เต็นท์ตรวจของชำรุด / ค่ำ
- Objective: ดูบาดแผลของคนเจ็บไปพร้อมกับโครงสร้างของไม้ที่ถูกใช้ในแนวรับ
- Conflict/Obstacle: อาการบาดเจ็บไม่เหมือนการโดนโจมตีตรง ๆ และแต่ละรายเล่าเหตุไม่ตรงกัน แถมคนเจ็บคนต่อไปกำลังถูกส่งเข้ามา
- Outcome: อีวานเริ่มแยกได้ว่าศัตรูใช้ของที่ทำให้ “การช่วย” กลายเป็นจุดตาย
- Reveal: ไม้สั่งตายถูกออกแบบให้ลงโทษระบบพยุงและการผลัดมือ
- Hook ปลายตอน: รอยข้างในนั้นเหมือนลายมือคนทำ

## ตอน 66: คนที่อ่านออก
- POV: อีวาน
- สถานที่/เวลา: ค่ายช่างชั่วคราว / กลางคืน
- Objective: รื้อชิ้นที่ชำรุดเพื่อหาโครงคิดของคนทำ
- Conflict/Obstacle: ชิ้นงานพังครึ่งหนึ่ง แต่ครึ่งที่เหลือกลับเหมือนจงใจเปิดทางให้คนที่อ่านเป็น
- Outcome: อีวานยืนยันว่าศัตรูไม่ได้ลอกเขาแบบหยาบ ๆ แต่เข้าใจจังหวะและลำดับคิดในระดับใกล้เคียง
- Reveal: ฝั่งตรงข้ามไม่ได้แค่มีช่างเก่ง พวกเขามีคนที่อ่านระบบงานของเขาออก
- Hook ปลายตอน: รอยหนึ่งบนแกนไม้ชนกับคำเรียกโบราณ

## ตอน 67: แฟ้มต้องห้าม
- POV: อีวาน
- สถานที่/เวลา: ห้องเก็บเอกสารแนวหน้า / ดึก
- Objective: เปิดแฟ้มเก่าพอให้รู้ว่าควรหยุดหรือเดินต่อก่อนแนวหน้าพังรอบถัดไป
- Conflict/Obstacle: เอกสารเก่าถูกล็อกเป็นชั้น ๆ และบางหน้าถูกลบชื่อออกด้วยเจตนา ไม่ใช่ความผิดพลาด
- Outcome: อีวานเห็นว่าข้อมูลนี้ไม่ใช่ประวัติศาสตร์ลอย ๆ แต่มันผูกกับของที่กำลังฆ่าคนอยู่ตอนนี้
- Reveal: ธีอาริสไม่ใช่ชื่อในแฟ้ม แต่เป็นรอยต่อที่พาไปถึงของจริง
- Hook ปลายตอน: หน้าหนึ่งในแฟ้มเอ่ยชื่อ “ธีอาริส”

## ตอน 68: ชื่อเมืองที่ไม่ควรเอ่ย
- POV: เซเรน่า
- สถานที่/เวลา: ห้องแสงต่ำในค่ายบัญชาการ / เช้า
- Objective: แปลบันทึกเก่าที่โยงธีอาริสกับอาวุธสั่งตายก่อนคำสั่งแนวหน้ารอบใหม่จะออก
- Conflict/Obstacle: ข้อมูลเก่ากระจัดกระจาย และบางส่วนขัดกันเองจนเหมือนถูกตั้งใจทำให้คนอ่านสับสน
- Outcome: เซเรน่าเห็นว่าชื่อเมืองนี้ไม่ใช่แค่ตำรา แต่มันเป็นกุญแจของอำนาจที่ยังทำงานอยู่
- Reveal: สี่นครไม่ใช่แผนที่ แต่เป็นโครงสร้างอำนาจ
- Hook ปลายตอน: ถ้าหลักการนี้หลุดไปถึงคนที่อ่านไม้เป็น เมืองทั้งเมืองจะไม่ปลอดภัยอีก

## ตอน 69: แผนที่สี่นครบนโต๊ะบัญชาการ
- POV: เวียรา
- สถานที่/เวลา: โต๊ะวางแผนหน้าแนว / กลางวัน
- Objective: ใช้ความรู้ใหม่ช่วยจัดแนวรับและขนคนเจ็บให้ปลอดภัยขึ้น
- Conflict/Obstacle: แผนที่สนามไม่พอ และเส้นทางส่งของเริ่มถูกศัตรูอ่านย้อน
- Outcome: เวียราเริ่มมองว่าสงครามนี้ไม่ใช่แค่การชนกันของกำลัง แต่เป็นการชนกันของระบบ
- Reveal: ชื่อของสี่นครเริ่มโผล่ในบทสนทนาทางทหารจริง ไม่ใช่แค่ในตำรา
- Hook ปลายตอน: เธอเห็นสัญลักษณ์บนลังส่งของที่เหมือนรอยเซ็นจากบันทึกเก่า

## ตอน 70: คนเจ็บที่รั้งแนวรับ
- POV: เวียรา
- สถานที่/เวลา: แนวพยาบาลหน้า / ค่ำ
- Objective: คุมทางคนเจ็บที่กำลังถูกส่งกลับหลังแนวปะทะ
- Conflict/Obstacle: การส่งต่อผิดจังหวะทำให้คนเจ็บทรุดซ้ำ และเวียราต้องเลือกว่าจะช่วยตรงไหนก่อน
- Outcome: เวียราเห็นผลจริงของไม้สั่งตายกับตาตัวเอง และรู้ว่าอาวุธนี้กินชีวิตผ่านงานช่วยเหลือ
- Reveal: ภัยของไม้สั่งตายคือมันทำให้การรักษากลายเป็นช่องสังหาร
- Hook ปลายตอน: ผู้ช่วยคนหนึ่งตายคามือ และเวียรารู้ว่ามีคนจงใจผิดจังหวะ

## ตอน 71: คทาในตำนาน
- POV: เซเรน่า
- สถานที่/เวลา: ค่ายบัญชาการชั่วคราว / ดึก
- Objective: ตัดสินใจว่าจะเปิดข้อมูลคทาให้ทีมช่างและสนามแค่ไหน
- Conflict/Obstacle: ถ้าเปิดมากไปจะกลายเป็นการโยนความลับระดับโลกให้หลุด ถ้าเปิดน้อยไปอีวานจะไม่มีกรอบพอรับมือ และแนวหน้าจะตัดสินใจผิด
- Outcome: เซเรน่าตกลงเปิดข้อมูลเท่าที่จำเป็น พร้อมล็อกชั้นความลับที่เหลือ
- Reveal: คทาไม่ใช่นิทาน
- Hook ปลายตอน: ศัตรูเริ่มใช้ถ้อยคำและรูปแบบการจัดวางของนครโบราณ

## ตอน 72: ความรู้ที่ถูกปิดไว้
- POV: อีวาน
- สถานที่/เวลา: ห้องอ่านแฟ้มลับ / เช้า
- Objective: อ่านชั้นข้อมูลที่ยอมเปิดให้เขาเพื่อเข้าใจไม้สั่งตายให้มากขึ้น
- Conflict/Obstacle: ข้อมูลถูกแบ่งเป็นชั้น ๆ และบางหน้าถูกปิดไว้ เพราะถ้าแปลผิด คนเจ็บรอบถัดไปจะถูกส่งเข้าจุดตาย
- Outcome: อีวานพอเห็นโครงว่าไม้สั่งตายไม่ได้เกิดลอย ๆ แต่พัฒนาจากความรู้เก่าที่เคยถูกเก็บแยกไว้

- Outcome: อีวานยืนยันว่าฝั่งตรงข้ามไม่ได้แค่มีอาวุธใหม่ แต่มีคนที่อ่านวิธีคิดของเขาได้
- Reveal: ความรู้ของเขาถูกย้ายไปเป็นอาวุธของอีกฝั่งแล้ว
- Hook ปลายตอน: รายงานชั้นลับปิดท้ายด้วยชื่อไฟล์ที่ผูกกับนครเก่าอีกครั้ง

## ตอน 89: แฟ้มลับที่ต้องเก็บ
- POV: เซเรน่า
- สถานที่/เวลา: ค่ายบัญชาการ / ดึก
- Objective: ตัดสินว่าจะพาความจริงระดับไหนกลับวาเลเรียน
- Conflict/Obstacle: ถ้าเปิดทั้งหมด เมืองจะตื่นตระหนก แต่ถ้าปิดทั้งหมด อีวานจะถูกทิ้งให้รับความผิดคนเดียว
- Outcome: เซเรน่าเลือกพาอีวาน, เวียรา, และแฟ้มบางส่วนกลับ พร้อมซ่อนข้อมูลส่วนที่ยังไม่พร้อมเปิด แต่ผูกเขาเข้ากับคำสั่งพิเศษชุดใหม่
- Reveal: สงครามนี้จะไม่จบในสนาม และวาเลเรียนจะต้องรับผลมันต่อ
- Hook ปลายตอน: อีวานต้องถูกส่งเข้าชุดรับมือไม้สั่งตายอย่างเป็นทางการ

## ตอน 90: ไม้กายสิทธิ์สั่งตาย
- POV: อีวาน
- สถานที่/เวลา: ระหว่างทางกลับวาเลเรียน / กลางคืน
- Objective: ยอมรับว่าเขาก้าวเข้ามาในสงครามอย่างถาวรแล้ว
- Conflict/Obstacle: เขากลัวสิ่งที่ตัวเองสร้างมากขึ้นทุกครั้งที่เห็นรายงานผลสนาม
- Outcome: อีวานตัดสินใจกลับไปวาเลเรียนพร้อมความรู้และความกลัวชุดใหม่ ในสถานะคนที่ถูกผูกเข้ากับการรับมืออาวุธนี้แล้ว
- Reveal: ไม้สั่งตายไม่ใช่จุดจบของปัญหา มันคือหลักฐานว่าความรู้เก่ากลับเข้ามาในสงครามแล้ว
- Hook ปลายตอน: มือของอีวานกำไม้แน่นกว่าตอนต้นอาร์ค

## หมายเหตุสำหรับผู้เขียน
- Arc นี้ต้องให้ความรู้สึกว่า “งานช่าง” ถูกบีบให้กลายเป็น “อาวุธของสงคราม” อย่างชัดเจน
- อย่ารีบเปิดความจริงเต็มของเอเรน, คาเอล, เซเวอแรนซ์, หรือรากโคโรบา
- คทาและสี่นครต้องเริ่มมีน้ำหนักจริงในปัจจุบัน แต่ยังไม่เฉลยลึกสุด
- เวียราต้องเป็นคนตรง แรง และลงสนามจริง ไม่ใช่คนวางเกมการเมือง
- ทุกครั้งที่อีวานช่วยชีวิตได้ ให้มีเงาของความเป็นอาวุธตามมาด้วย
- ปลาย Arc ควรทิ้งภาพจำเดียวที่ชัด ไม่ใช่เปิดสงครามเต็มตัวหลายชั้น
- ตอน 67–72 ต้องคุมไม่ให้ `ธีอาริส / สี่นคร / คทา / ความรู้ที่ถูกปิด` ไหลติดกันจนแน่นเกินอ่าน
- ตอน 80 ต้องเน้นการเมืองและอำนาจ ส่วนตอน 89 ต้องเน้นภาระและผลจากสนามที่ตกใส่อีวานโดยตรง
- ตอน 90 ถ้าลงฉากจริง ให้ปิดด้วยภาพของขบวนกลับเมือง, มือที่กำไม้, หรือรายงานที่พับเก็บอยู่ข้างตัว อย่างใดอย่างหนึ่ง
