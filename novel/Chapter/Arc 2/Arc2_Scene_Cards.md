# Arc 2 — ช่างแห่งวาเลเรียน: Scene Cards (30 ตอนเต็ม)

## Overview
- ชื่อ Arc: ช่างแห่งวาเลเรียน
- ช่วงตอน: 31–60
- ช่วงเวลา canon: `Month 2–4`
- เป้าหมายของ Arc: ทำให้อีวานจาก “ช่างหนุ่มที่วาเลเรียนเพิ่งยอมรับ” กลายเป็นคนที่เริ่มเปลี่ยนมาตรฐานของทั้งเมือง และทำให้คนอ่านเห็นชัดว่าความรู้ของเขาไม่ได้อยู่แค่บนโต๊ะงาน แต่เริ่มกลายเป็นโครงสร้างของรัฐ
- หน้าที่ของ Arc:
  1. ขยายโลกจากงานช่างรายบุคคลไปสู่งานช่างเชิงระบบ
  2. ทำให้วาเลเรียนดูเป็นเมืองที่มีหลายอำนาจ ไม่ใช่เสียงเดียว
  3. ดันความสัมพันธ์อีวาน–เวียราให้แน่นขึ้นจาก “ร่วมทาง” เป็น “ยืนข้างกันจริง”
  4. ให้ความสำเร็จของอีวานเริ่มมีราคาทางการเมืองและความปลอดภัย
  5. ปักสัญญาณว่าฝั่งศัตรูเริ่มเก็บข้อมูลการออกแบบของเขาอย่างเป็นระบบ
- จุดพีคกลาง Arc: ตอน 45–46 ต้องเป็นการชนกันต่อหน้าคณะตรวจและคนจริง จนมาตรฐานของเมืองแตกให้เห็นว่าใครกำลังใช้ระบบเป็นอาวุธ
- กติกา arc นี้:
  - ยังไม่เปิดความจริงเต็มของเอเรน, คาเอล, เซเวอแรนซ์, หรือรากโคโรบา
  - ให้เงาของการสืบรอยสำคัญกว่าการเฉลย
  - อย่าให้บีท “มีคนแตะห้อง/แอบเข้าไปดูงาน” กลายเป็นรูปแบบหลักซ้ำ ๆ ให้สลับไปที่เครดิต, มาตรฐาน, คำสั่ง, และการลอกแบบ
  - ทุกความสำเร็จต้องมีราคาหรือความเสี่ยงตามมา

## ตอน 31: ห้องที่ถูกเปิดก่อนเจ้าของ
- POV: อีวาน
- สถานที่/เวลา: ห้องทดลองย่อยฝั่งตะวันออก / เช้ามืด
- Objective: ตรวจหาว่าใครเข้าไปแตะห้องของเขาก่อนจะได้สิทธิ์ใช้งานจริง
- Conflict/Obstacle: ห้องที่ดูเหมือนปลอดภัยกลับมีร่องรอยการเปิดผนึก, ผงร่าง, และการขยับของที่ไม่ควรถูกแตะ
- Outcome: อีวานยืนยันว่ามีคนเข้าห้องก่อนเขา และไม่ได้เข้ามาแบบขโมยของอย่างเดียว
- Reveal: คนที่เข้ามารู้ว่าควรแตะอะไร, ไม่แตะอะไร, และกำลังวัดขอบเขตความรู้ของเขา
- Hook ปลายตอน: อีวานพบร่องรอยเล็กมากที่ชี้ว่าคนที่เข้าห้องอาจมีสิทธิ์ผ่านระบบบางส่วนของวาเลเรียนอยู่แล้ว

## ตอน 32: สิทธิ์ของใคร
- POV: อีวาน
- สถานที่/เวลา: ห้องประชุมย่อยของหน่วยวิจัย / วันเดียวกัน
- Objective: รับสถานะใหม่และทำให้แน่ใจว่าเขายังมีอิสระพอจะทำงานจริง
- Conflict/Obstacle: ฝ่ายอนุรักษนิยมอยากให้เขาอยู่ในกรอบควบคุม ส่วนฝ่ายสนับสนุนยังมองเขาเป็นความเสี่ยง
- Outcome: เขาได้สถานะช่างประจำโครงการคุ้มกันชั่วคราว แต่ยังต้องถูกจับตา
- Reveal: วาเลเรียนต้องการผลงานของอีวานเร็วกว่าที่เขาคิด และระบบเริ่มขยับเข้ามาใกล้ตัวเขาแล้ว
- Hook ปลายตอน: ลูเซียนส่งคำสั่งแรกจากหอพยาบาลเข้ามาว่า ต้องการวิธีลดภาระของทั้งหอภายในไม่กี่วัน

## ตอน 33: มือไม่พอ
- POV: อีวาน
- สถานที่/เวลา: หอพยาบาล / กลางวัน
- Objective: แก้ปัญหาการประคองผู้บาดเจ็บและไม้ที่เริ่มเสื่อมจากการใช้งานหนัก
- Conflict/Obstacle: ระบบรักษาของหอพยาบาลกินแรงคนรักษามากเกินไป และอุปกรณ์เวทมาตรฐานไม่พอรับภาระจริง
- Outcome: อีวานช่วยลดงานประคองบางส่วนได้ด้วยแนวคิดเชิงช่างแบบใหม่ แต่ต้องยอมปิดเตียงหนึ่งชั่วคราวเพื่อปรับระบบ
- Reveal: หอพยาบาลไม่ได้แค่ต้องการหมอ แต่ต้องการโครงสร้างเครื่องมือที่ดีขึ้นด้วย
- Hook ปลายตอน: ลูเซียนขอให้เขาลองออกแบบของที่ “ใช้ซ้ำได้” แทนการซ่อมเฉพาะหน้า และต้องใช้กับคนจริงต่อจากนี้

## ตอน 34: ของที่ไม่ต้องแพง
- POV: อีวาน
- สถานที่/เวลา: เรือนวิจัย / ค่ำ
- Objective: พิสูจน์ว่าวัสดุสามัญสามารถทำงานระดับสูงได้ ถ้าออกแบบถูก
- Conflict/Obstacle: คนในห้องทดลองและคนรอบข้างยังเชื่อว่าของแพงต้องดีกว่าเสมอ และมองว่างานของเด็กจากออเรนทิสไม่ควรแตะโต๊ะของวาเลเรียน
- Outcome: ต้นแบบแรกที่ใช้วัสดุธรรมดาให้ผลดีกว่าของหรูในงานเฉพาะทาง และทำให้คนที่คัดหน้าตาเริ่มเงียบ
- Reveal: เอกลักษณ์ของอีวานคือการจับคู่และจัดโครง ไม่ใช่แค่หาของชั้นดี
- Hook ปลายตอน: มีคนในห้องขอดูบัญชีวัสดุละเอียดผิดปกติ พร้อมน้ำเสียงเหมือนกำลังประเมินว่าเขาคู่ควรกับโต๊ะนี้หรือไม่

## ตอน 35: ชื่อบนโต๊ะอำนาจ
- POV: อีวาน
- สถานที่/เวลา: สำนักงานย่อย/ห้องตรวจงาน / วันถัดมา
- Objective: ปกป้องงานของตัวเองไม่ให้ถูกคนอื่นเอาไปลงชื่อหรือผูกเครดิต
- Conflict/Obstacle: คนบางกลุ่มในวาเลเรียนเริ่มอยาก “ซื้อ” ความคิดของเขา และทำให้มันกลายเป็นทรัพย์สินระบบ
- Outcome: อีวานปฏิเสธการผูกขาดแบบสุภาพ แต่ชัดเจน
- Reveal: ชื่อของเขาเริ่มมีน้ำหนักในระบบเมืองจริง ๆ แล้ว
- Hook ปลายตอน: เอกสารทดสอบฉบับหนึ่งโผล่มาพร้อมลายเซ็นที่เขาไม่ได้เป็นคนเขียน

## ตอน 36: เวรดึกของช่าง
- POV: อีวาน
- สถานที่/เวลา: หอพยาบาล / กลางคืน
- Objective: ทำงานข้ามคืนเพื่อให้ระบบลดแรงคนได้จริง
- Conflict/Obstacle: คนเจ็บเยอะ เวลาน้อย และทุกนาทีที่เสียไปมีราคาเป็นชีวิต
- Outcome: เขาสร้างชุดซ่อม/จูนที่ช่วยหอพยาบาลลดภาระได้จริง แต่ต้องยอมตัดคุณสมบัติหนึ่งออกเพื่อให้ของทนพอ
- Reveal: งานของเขาเริ่มเป็นโครงสร้างพื้นฐาน ไม่ใช่แค่ชิ้นงานทดลอง
- Silent Beat: หลังคนในหอหลับหมด อีวานนั่งซ่อมชิ้นเล็กของพ่อเพียงชิ้นเดียว แล้วเก็บมันกลับไว้โดยไม่พูดอะไร
- Hook ปลายตอน: อีวานสังเกตว่ามีคนจดจังหวะทำงานของเขาแบบละเอียดเกินไป

## ตอน 37: โรงเรียนที่ไม่ชอบเด็กคนนี้
- POV: อีวาน
- สถานที่/เวลา: ห้องประชุมช่าง / กลางวัน
- Objective: สอนวิธีมาตรฐานใหม่ให้ช่างอื่นเห็นว่าทำซ้ำได้จริง
- Conflict/Obstacle: ช่างรุ่นเก่าไม่ชอบให้เด็กจากออเรนทิสมาแตะมาตรฐานของวาเลเรียน
- Outcome: เขาเอาชนะบางคนด้วยผลลัพธ์ แต่ก็ทำให้ศัตรูเชิงสถาบันเพิ่มขึ้น
- Reveal: วาเลเรียนมีหลายโรงเรียนความคิด และไม่ใช่ทุกคนต้องการสิ่งเดียวกัน
- Hook ปลายตอน: ช่างอาวุโสคนหนึ่งขอคุยกับอีวานส่วนตัวหลังห้องว่างลง

## ตอน 38: เวียราในห้องทดลอง
- POV: เวียรา
- สถานที่/เวลา: ห้องทดลองย่อยฝั่งตะวันออก / ค่ำ
- Objective: ตัดสินใจว่าจะเป็นแค่คนดูงาน หรือเป็นคนแรกที่ยืนคุมหน้าห้องให้เขา
- Conflict/Obstacle: เวียราเห็นเขาถูกดึงไปทุกทิศ ทั้งงาน ความคาดหวัง และสายตาคนอื่น จนถ้าปล่อยไว้ ระบบจะเอาตัวเขาไปทีละชั้น
- Outcome: เวียราตัดสินใจใช้สถานะของตัวเองกันพื้นที่ให้เขา และขยับจากคนช่วยทดสอบไปเป็นคนคุมจังหวะข้างหน้า
- Reveal: ความสัมพันธ์ของทั้งคู่ขยับจาก “พึ่งพา” ไปสู่ “เลือกกัน” และเริ่มมีผลต่อทิศทางงานจริง
- Hook ปลายตอน: เวียราเห็นสัญญาณว่าห้องของอีวานถูกเปิดอีกครั้ง ทั้งที่เพิ่งตรวจไปไม่นาน และรู้ว่าต้องเป็นคนจัดการเอง

## ตอน 39: รอยที่ไม่ใช่ของช่าง
- POV: อีวาน
- สถานที่/เวลา: ห้องตรวจงานและบันทึกการส่งของ / กลางคืน
- Objective: จับต้นตอของการแทรกแซงซ้ำ ๆ ในบันทึกและเครื่องมือ
- Conflict/Obstacle: คนที่ขยับงานไม่ทิ้งร่องรอยตรง ๆ และรู้วิธีเลี่ยงการสังเกตของช่าง แต่ร่องรอยกลับโผล่ในเอกสารที่ผ่านมือคณะตรวจ
- Outcome: อีวานตั้งระบบทำเครื่องหมายและเริ่มเห็นรูปแบบการแทรก แต่ความรู้สึกคือถูกคนแปลกหน้าล้วงเข้าไปในหัว
- Reveal: คนที่แตะงานของเขาไม่ได้สนใจของสำเร็จอย่างเดียว แต่กำลังอ่านวิธีคิดของเขาผ่านบันทึกและจังหวะส่งงาน และนั่นทำให้เขารู้สึกเหมือนตัวตนถูกละเมิด
- Hook ปลายตอน: เครื่องหมายเดิมโผล่ในบันทึกตรวจงานของหอทดลองที่เขาไม่ได้เป็นคนส่ง พร้อมจังหวะที่ตรงกับนิสัยการจัดโต๊ะของเขา

## ตอน 40: งานที่เริ่มสอนคนอื่นได้
- POV: อีวาน
- สถานที่/เวลา: เรือนฝึก / เช้า
- Objective: ทำให้วิธีของเขากลายเป็นงานที่คนอื่นทำตามได้
- Conflict/Obstacle: ยิ่งสอน ยิ่งต้องตัดรายละเอียด และยิ่งเสี่ยงให้เกิดความเข้าใจผิด
- Outcome: เขาได้รูปแบบงานที่เริ่มส่งต่อได้จริง แต่หนึ่งชิ้นกลับถูกใช้ผิดจนต้องแก้ต่อหน้าคนอื่น
- Reveal: แนวคิดของอีวานเริ่มมีโครงแบบสาธารณะ ไม่ใช่ทักษะเฉพาะตัวอย่างเดียว
- Hook ปลายตอน: มีคำขอเร่งด่วนจากแนวหน้าเข้ามา ขอเวอร์ชันที่เหมาะกับสนามมากกว่าเดิม

## ตอน 41: คำขอจากแนวหน้า
- POV: อีวาน
- สถานที่/เวลา: ห้องทำงาน / บ่าย
- Objective: ตอบคำขอจากแนวหน้าด้วยของที่พอส่งได้ทัน
- Conflict/Obstacle: เดดไลน์สั้น วัสดุจำกัด และความเสี่ยงสูงถ้าของไม่ทนสนาม
- Outcome: เขาส่งต้นแบบสำหรับผู้ใช้ภาคสนามได้สำเร็จ
- Reveal: งานของเขาเริ่มถูกนับเป็นส่วนหนึ่งของสงคราม แม้ยังอยู่ในเมือง
- Hook ปลายตอน: รายงานจากแนวหน้าพูดถึงอาวุธหรือพฤติกรรมเวทที่คล้ายหลักการของเขาเกินไป

## ตอน 42: กลิ่นท่าเรือในผงสีเทา
- POV: อีวาน
- สถานที่/เวลา: ห้องตรวจวัสดุ / ค่ำ
- Objective: ตามรอยวัสดุผิดปกติที่ใช้ในตัวอย่างและการซ่อมแซม
- Conflict/Obstacle: เส้นทางของวัตถุดิบบางส่วนลากไปถึงท่าเรือและช่องทางสีเทา จนกลิ่นดินชื้นกับเกลือคาวเหมือนหลุดเข้ามาในโต๊ะตรวจเอง
- Outcome: อีวานเริ่มโยงงานในวาเลเรียนเข้ากับเครือข่ายภายนอก และรู้สึกว่าคนจากนอกระบบกำลังเอื้อมถึงของบนโต๊ะเขาจริง ๆ
- Reveal: เมอริดัสและโลกการค้าใต้ดินเริ่มมีเงามาแตะงานของเขา
- Hook ปลายตอน: เขาพบเครื่องหมายจากช่องทางค้าที่ไม่ควรอยู่ในห้องทดลองของรัฐ และมันอยู่ใกล้พอจะทำให้รู้สึกเหมือนมีคนยืนอยู่หลังไหล่

## ตอน 43: คนที่เรียนรู้เร็วเกินไป
- POV: อีวาน
- สถานที่/เวลา: ห้องฝึกช่าง / วันต่อมา
- Objective: ให้ช่างรุ่นใหม่เรียนวิธีของเขาและเริ่มช่วยกันทำงาน
- Conflict/Obstacle: บางคนเข้าใจเร็วเกินไป บางคนก็เอาไปใช้ผิด
- Outcome: อีวานสร้างแกนการเรียนรู้ขั้นพื้นฐานที่พอส่งต่อได้ แต่คนช่วยตัวเล็กที่ชอบนั่งลอกจังหวะมือของเขาเริ่มหายไปจากโต๊ะอย่างผิดปกติ
- Reveal: วิธีของเขาเริ่มมีผลต่อคนอื่น ไม่ได้จำกัดแค่ผู้สร้าง
- Hook ปลายตอน: ผู้ช่วยคนนั้นทิ้งชิ้นงานที่ยังไม่เสร็จไว้กับบันทึกสั้น ๆ ว่า “เดี๋ยวมา” แต่ไม่กลับมาอีก

- Hook ปลายตอน: ข้อกำหนดใหม่บังคับให้อีวานต้องเปิดผลงานบางส่วนต่อคณะตรวจในวันสาธิต ถ้าพลาดจะเสียสิทธิ์ใช้งานทั้งหมด

- Hook ปลายตอน: คณะตรวจสั่งระงับงานทั้งหมดและเรียกอีวานขึ้นสอบสวนต่อหน้าผู้มีอำนาจ

- Hook ปลายตอน: หนึ่งในต้นแบบมีลายโครงที่โยงกลับไปถึงเส้นทางวัสดุที่เริ่มแตะเมอริดัส

- Reveal: ยิ่งดัง ยิ่งมีคนอยากเป็นเจ้าของชื่อเขา
- Hook ปลายตอน: มีข้อความสั้นจากคนไม่ลงชื่อ ส่งมาถึงเขาผ่านช่องทางที่ไม่ควรใช้ได้ในวาเลเรียน พร้อมตัวเลขที่มากพอจะทำให้ข้อเสนอเดิมน่าหวั่นไหวขึ้นอีกชั้น

- Hook ปลายตอน: การตัดหน้าของเธอทำให้มีคนเปลี่ยนไปใช้ช่องทางลับแทนช่องทางทางการทันที และมีคนท้วงว่าเธอใช้อำนาจของมิราเคิลเมจเกินขอบเขต

- Conflict/Obstacle: คนดูเยอะเกินไป และทุกสายตาพร้อมจะเปลี่ยนงานทดลองให้กลายเป็นการตัดสินชื่อเสียง
- Outcome: อีวานผ่านการทดสอบ แต่กดดันตัวเองมากขึ้นไปอีก เมื่อได้ยินคนเรียกต้นแบบของเขาด้วยชื่อทางทหารครั้งแรก
- Reveal: ชื่อของเขาเริ่มมีผลต่อการตัดสินเชิงนโยบาย และงานของเขาเริ่มถูกมองด้วยภาษาแบบทหาร
- Hook ปลายตอน: ข้อความด่วนจากแนวหน้ามาถึงว่า ต้องการรุ่นที่ “ไม่ควรมีอยู่” มากกว่านี้ แต่ยังไม่ขอใช้มันเดี๋ยวนี้

## ตอน 59: คำตอบที่เกินจะเก็บ
- POV: อีวาน
- สถานที่/เวลา: ห้องทำงาน / กลางคืน
- Objective: ตอบคำขอจากแนวหน้าด้วยต้นแบบที่พร้อมใช้งานจริง
- Conflict/Obstacle: ความต้องการสนามรบกำลังลากเขาไปไกลกว่างานซ่อมปกติ และยิ่งใกล้คำตอบ เขายิ่งเห็นภาพว่ามันอาจกลายเป็นอาวุธที่เขาเองหยุดไม่ได้
- Outcome: เขาเริ่มก้าวสู่การออกแบบที่แตะระดับสงครามโดยตรง แต่มีช่วงหนึ่งต้องหยุดมือเพราะนึกภาพผลลัพธ์ในสนามแล้วไม่อยากไปต่อ และเก็บแบบร่างลงลิ้นชักเหมือนซ่อนบางอย่าง
- Reveal: ต้นแบบใหม่ของเขาเริ่มมีน้ำหนักพอจะเปลี่ยนวิธีรบได้ และนั่นทำให้เขากลัวมันมากกว่าที่ควร
- Hook ปลายตอน: รายงานทดสอบบอกว่าพฤติกรรมของต้นแบบคล้ายอาวุธแบบ “สั่งตาย” มากขึ้นจนเขาไม่แน่ใจว่าควรส่งออกไปหรือไม่

## ตอน 60: คืนที่วาเลเรียนไม่เงียบ
- POV: อีวาน
- สถานที่/เวลา: ห้องทดลองย่อยฝั่งตะวันออก / ดึก
- Objective: ปิด Arc 2 ด้วยการยืนยันสถานะของตัวเองและตั้งรับการตอบโต้
- Conflict/Obstacle: เขาเริ่มเป็นคนสำคัญของรัฐ แต่ก็ถูกจับตาและถูกทดลองกลับไปด้วย
- Outcome: อีวานยอมรับบทบาทช่างประจำโครงการโดยยังพยายามรักษาเสียงของตัวเองไว้ แต่ครั้งแรกที่ได้อ่านผลสนาม เขาเงียบไปนานกว่าที่เคย
- Reveal: ฝั่งศัตรูเริ่มตอบสนองต่อสิ่งที่เขาสร้างอย่างชัดเจน และเขาเริ่มกลัวว่าของที่ออกจากมือจะไม่กลับมาเป็นแค่ผลงานอีกแล้ว
- Hook ปลายตอน: คืนจบด้วยรายงานจากแนวหน้าว่าต้นแบบของเขาถูกใช้จริงในสนาม และมีคนตายเพราะมันเร็วกว่าที่เขาคิดไว้ ขณะที่มือของเขาสั่นตอนวางกระดาษลงเป็นครั้งแรก

## หมายเหตุสำหรับผู้เขียน
- Arc นี้ควรให้ความรู้สึกว่า “งานช่าง” กลายเป็น “อำนาจ” ทีละก้าว
- ห้ามรีบเปิดคาเอล, เอเรน, หรือโครงลึกของเซเวอแรนซ์เกินสิ่งที่ไทม์ไลน์อนุญาต
- ถ้าจะวางภัยซ้ำ ให้เปลี่ยนรูปแบบภัย ไม่ใช่ใช้การแตะห้องหรือแอบเข้าห้องเป็นแพตเทิร์นหลัก
- ตอน 55 ควรวางหมากแบบพอให้คนอ่านรู้ว่ามีอะไรเปลี่ยน แต่ไม่อธิบายกับดักหมด
- ตอน 56 ค่อยให้ผลของหมากออกมา และอย่าซ้ำข้อมูลฝั่งวางแผนเกินจำเป็น
- ให้ธีม “ควรเก็บความรู้นี้ไว้กับใคร” ปรากฏเป็นคำถามในฉากตัดสินใจและฉากหลังผลสนามทุกครั้งที่ทำได้
- เวียราต้องไม่ใช่แค่แรงค้ำอีวาน แต่ต้องมีราคาที่เธอจ่ายกับสถานะของตัวเองด้วย
- เวียราในตอน 50 และ 56 ควรยังเป็นเวียราที่ตรง แรง กล้าชน อย่าเขียนให้เก่งทางการเมืองหรือเล่นเกมสภาเนียน ๆ เกินธรรมชาติของเธอ
- ตอน 58–60 ต้องจบที่ความกลัวเริ่มเกิด ไม่ใช่ดราม่าหนักจนเหมือน Arc 3 เปิดเต็มตัว แม้จะมีคนตายเพราะงานของอีวานได้
- ตอน 58–60 ควรมีภาพจำปลายอาร์คเพียงหนึ่งภาพที่ติดอยู่ในหัว ไม่ต้องยัด climax หลายชั้นจนกลายเป็นเปิดสงครามเต็มตัว
- note สำหรับตอนเขียน:
  - ตอน 58 = โลกเริ่มมองงานเขาเป็นของสงคราม
  - ตอน 59 = เขาเริ่มกลัวสิ่งที่ตัวเองกำลังสร้าง
  - ตอน 60 = ผลลัพธ์จากโลกจริงย้อนกลับมาทิ่มเขา
- ใช้เวียราเป็นแกนความใกล้ชิดและเป็นคนค้ำสถานะอีวานทางอารมณ์ได้มากขึ้น
- ลูเซียนและเซเรน่าควรทำหน้าที่เป็นเสาหลักด้านระบบและแรงคุ้มกัน
- ตอนพักหายใจใน Arc นี้ควรเป็นตอนที่ “ช้าแต่ไม่ปลอดภัย”
- ทุกครั้งที่อีวานแก้ปัญหาได้ ให้มีใครสักคนเริ่มถามว่าควรเก็บความรู้นี้ไว้กับใคร
