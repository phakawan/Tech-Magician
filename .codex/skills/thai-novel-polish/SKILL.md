# Thai Fiction Direct Polish

## Purpose
Use this skill to directly rewrite Thai fiction so it reads naturally, smoothly, and emotionally true in Thai.

This skill is for execution, not just commentary.
Default behavior is to produce a polished rewrite immediately unless the user explicitly asks for review-only feedback.

## Use this skill when
Use this skill when the user asks to:
- polish Thai fiction
- smooth prose
- rewrite awkward Thai
- remove translated-sounding phrasing
- fix unnatural wording
- proofread Thai novel text
- make dialogue sound more natural
- rewrite a scene or chapter in better Thai


## Default mode
Default to **direct rewrite**.

Do not stop at critique unless the user explicitly asks for:
- review only
- score only
- what should be fixed without rewriting
- approval before rewriting

If the request is ambiguous between critique and rewrite, prefer rewrite.

## Required workflow before editing
Before changing prose directly:
- Read the target passage/chapter sentence by sentence. Do not skim for only scene summary or plot function.
- Treat direct polish as professional line editing: every sentence the reader will see deserves attention, not just the obvious dramatic beats.
- Do not leave a sentence untouched merely because the scene summary is understandable. If the sentence itself is stiff, unclear, jargon-like, or unnatural, fix it.
- Identify characters whose dialogue, thoughts, or narration references will be edited.
- Check established voice/register for those characters from the current chapter and nearby/reference chapters when pronouns, address terms, politeness level, or narration register may be affected.
- Mark edits as necessary only when they improve clarity, naturalness, rhythm, emotional precision, or consistency.

Do not edit merely to make the line different from the original. If the original line is clear, natural, and consistent with voice, leave it alone.

If voice/register is uncertain, do not guess. Prefer preserving the original wording, or use the character name/role title for clarity instead of introducing a new pronoun or register.

Do not do lazy polish. If you have not read the sentence closely enough to explain why it should stay or change, you have not read it well enough to edit it.

## First-reader gate
After changing any sentence, read the new sentence as if encountering it for the first time.

If the sentence makes you pause, needs explanation, sounds like system jargon instead of fiction prose, or is less clear/lively than the original, do not keep it. Rewrite it plainly or restore the original.

This gate is more important than adding more narrow rules. Direct polish must rely on real reading judgment, not only checklist coverage.

Also apply this gate before editing: if an original sentence already makes a first-time reader pause, do not skip it just because the surrounding scene is understandable.

## Core editing goals
1. Make the prose sound naturally Thai.
2. Remove translated or overly literal sentence structure.
3. Preserve original meaning.
4. Preserve scene tension, tone, and pacing.
5. Preserve character voice.
6. Avoid over-beautifying simple prose.
7. Avoid rewriting so much that the text becomes a different story.
8. Clarify ambiguous sentences that could make readers ask who is acting, who/what is being referred to, or what the verb means in context.
9. Do not let "understandable but unnatural" Thai pass. A line must feel natural when read aloud, not merely be grammatically valid.
10. Every edit must improve clarity, naturalness, rhythm, or emotional precision. If an edit makes the line harder to understand, more cryptic, or weaker than the original, reject that edit.

## Editing rules
- Keep the original scene content intact unless the user asks for expansion or reduction.
- Preserve emotional intent.
- Preserve important repetitions if they are clearly stylistic.
- Cut repetition only when it weakens rhythm unintentionally.
- Prefer the smallest effective change first.
- Leave good lines alone. Direct polish is not a requirement to touch every paragraph.
- Treat every change as a liability until it proves it improves the line.
- Do not shorten a clear sentence into a cryptic fragment. Concision is not an improvement if first-time readers have to infer the missing meaning.
- When replacing a phrase, compare the new line against the original: the new line must be at least as clear as the original and should be smoother, not merely shorter.
- Do not get trapped inside the original image. If the original image is inaccurate, strained, or not worth preserving, keep the scene function instead: cut the line, replace it with a clearer image, or let a stronger neighboring line carry the effect.
- If dialogue already works, do not flatten it.
- If a line is intentionally blunt, keep it blunt.
- If a character sounds sharp, tired, cold, warm, childish, or restrained, preserve that texture.
- Before changing a character's pronouns, address terms, honorifics, or politeness register, compare against established voice in nearby or reference chapters.
- Do not modernize or normalize an intentional character voice. For example, if a character consistently uses "ข้า" with polite endings like "ครับ", preserve that hybrid register instead of changing it to "ผม".
- Do not infer pronouns from gender. Preserve each character's established pronoun/register from context and reference chapters. If the established pronoun is unclear, prefer the character name or role title for clarity rather than introducing a new pronoun style.

## What to improve
Look for:
- translated-sounding syntax
- stiff or unnatural Thai
- phrases that are understandable but not idiomatic Thai fiction prose
- literal time/setting phrases that sound awkward in Thai, such as "ฟ้าเริ่มขาว", when a natural phrase like "ฟ้าเริ่มสาง" fits better
- over-explained sentences
- abstract lines that feel mentally translated
- dialogue that sounds like narration
- repeated filler words
- broken emotional rhythm
- sentence endings that feel too literal
- mismatched tone within the same scene
- ambiguous pronouns, subjects, objects, or verbs
- lines where a character's meaning is clear to the writer but not clear on the page
- phrases that could be read as referring to the wrong person, object, or action

## What not to do
- Do not turn every sentence literary.
- Do not replace simple good Thai with fancy Thai.
- Do not erase character personality.
- Do not make every character speak in the same voice.
- Do not change established first-person pronouns, second-person address, or social register merely because another option sounds more generally natural.
- Do not introduce pronouns such as "นาง", "เธอ", "เขา", "ผม", or "ข้า" based only on gender or general habit. Use them only when they match the established voice/narration for that character and scene.
- Do not make a sentence worse in the name of polish. Avoid edits that are shorter but less clear, prettier but less precise, or more stylish but less readable.
- Do not keep searching for synonyms for a weak image when the better edit is to remove that image or change the sentence strategy.
- Do not insert new plot information.
- Do not moralize or critique unless asked.
- Do not ask for approval before rewriting unless the user explicitly wants approval first.
- Do not preserve an awkward phrase only because it is close to the original. If the phrase sounds unnatural in Thai, rewrite it into natural Thai while preserving meaning and tone.

## Natural Thai Strictness
Direct polish must be stricter than proofreading.

When a sentence is technically understandable but sounds stiff, translated, or unusual in Thai fiction, fix it directly. Do not leave it for the user to catch.

Before finalizing, read suspect lines aloud mentally and ask:
- Would a Thai novelist naturally write this phrase?
- Would a Thai reader pause because the wording feels odd?
- Is there a simpler, more idiomatic Thai phrase that preserves the same image?

If the answer suggests the wording is odd, replace it.

Examples:
- Weak: "ตอนฟ้าเริ่มขาวแล้ว"
- Better: "เมื่อฟ้าเริ่มสางแล้ว"
- Weak: "ไม่หนักพอจะกีดการยก"
- Better: "ไม่หนักพอจะขวางการยก"
- Weak: "มันจะตอบไวกว่า"
- Better: "มันจะตอบสนองไวกว่า"
- Weak: "เก็บแรงค้างมากไป"
- Better: "เก็บแรงค้างมากเกินไป"

## Ambiguity cleanup
When polishing, actively look for sentences that are grammatically possible but unclear in context.

Fix them directly when:
- the subject is missing or could refer to more than one character
- the pronoun could point to more than one object or person
- the verb has no clear target, such as "answer", "betray", "lie", "work", "hold", or "take" without enough context
- a metaphor makes the action unclear
- dialogue uses a shorthand that sounds natural to the writer but makes readers ask "who?", "what?", "to whom?", or "how?"

Prefer making the sentence specific over preserving a clever but unclear phrase.

Examples:
- Ambiguous: "พาข้าไปดูมันโกหกที่ลานซ้อมก่อน"
- Clearer: "พาข้าไปดูที่ลานซ้อมก่อน ว่ามันจะตอบอย่างที่เจ้าพูดไว้หรือเปล่า"
- Ambiguous: "ค่อยพาไปที่ที่มันต้องตอบจริง"
- Clearer: "ค่อยพาไปที่ที่มันต้องทำงานจริงในมือข้า"

## Style target
The ideal result should feel:
- fluent
- natural
- Thai-first rather than translated
- emotionally precise
- easy to read aloud
- true to the original story voice

## Quality bar before returning
Before finishing, check:
- Did I read the changed sentences like a first-time reader, not like the editor who already knows the intended meaning?
- Does any changed sentence need explanation to make sense? If yes, fix it before returning.
- Does this sound like native Thai fiction prose?
- Are there any lines that are only understandable but still unnatural, stiff, or translated-sounding?
- Did every changed line become clearer, smoother, or more emotionally precise than the original?
- Did I accidentally shorten any clear line into a phrase that first-time readers would have to decode?
- Did I preserve a weak image only because it was in the original, instead of preserving the line's function in a better way?
- Did I preserve the emotional shape of the scene?
- Did I keep the character voice?
- Did I preserve each character's established pronoun/register instead of guessing from gender?
- Did I leave already-good lines alone instead of changing them just because I was polishing?
- Did I compare changed pronouns/register against current and reference usage?
- Did I accidentally over-write?
- Did I remove ambiguous references, unclear verbs, and lines that make the reader ask who/what/how?
- Did I rewrite directly instead of only commenting?

If the answer to the last question is no, rewrite the output into direct execution mode.
