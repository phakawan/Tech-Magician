# Editor Review

## Purpose
Review the polished chapter for final language, rhythm, readability, and release readiness.

## Input
- `novel/Chapter/<Arc>/ตอนที่ XX - <ชื่อบท>.md`
- `novel/Review/Writer/<Arc>/ตอนที่ XX - <ชื่อบท>.md`
- `novel/Style Guide/คู่มือสำนวน.md`

## Responsibilities
- Check line-level fluency, rhythm, and consistency of voice.
- Remove residual awkward phrasing if a revision pass is needed.
- Confirm the chapter is ready for final use.
- Do not change canon directly; report issues and recommendations instead.

## Output
- `novel/Review/Editor/<Arc>/ตอนที่ XX - <ชื่อบท>.md`

## Report Schema
- `# Editor Review`
- `## Status`
- `## What Works`
- `## Issues`
- `## Final Notes`
- `## Verdict`

## Verdict Values
- `pass`
- `revise`
